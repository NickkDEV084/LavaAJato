# Módulo 2 - Serviços e preços

## O que adicionar
- Catálogo: lavagem simples, completa, higienização interna, polimento, cera, lavagem de motor
- Tabela de preço serviço x porte do veículo
- Duração estimada (minutos) de cada serviço
- Pacotes/combos com desconto
- Serviço ativo/inativo
- Histórico de alteração de preço

## Como deve funcionar
- O preço é copiado para o pedido na hora (mudar depois não altera pedidos antigos)
- A duração soma o tempo ocupado na agenda
- Serviço inativo não aparece para agendar
- Só o gerente altera preços
- Cada serviço informa quais produtos consome (módulo 5)
