# Módulo 8 - Avaliações e relatórios

## O que adicionar
- Nota de 1 a 5 e comentário após a entrega
- Relatórios: faturamento (dia, semana, mês), serviços mais vendidos, ocupação da agenda, tempo médio de atendimento
- Cancelamentos, consumo e estoque baixo, clientes frequentes, média de avaliações
- Filtro por período
- Exportar em CSV ou PDF

## Como deve funcionar
- Avaliação só para pedidos entregues, uma por pedido
- Nota 2 ou menos gera alerta ao gerente
- Relatórios apenas leem os dados dos outros módulos
- Relatórios financeiros só para o gerente
